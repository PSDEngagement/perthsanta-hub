Instagram Engagement

Danh sách bài cần chạy số. Thêm / sửa bài trong data.json → mảng instagram.

Cách thêm 1 bài mới (copy khối JSON) 
{
  "id": "2026-09-24-perth-1",
  "date": "2026-09-24",
  "handle": "@perthppe",
  "title": "Caption ngắn để nhận bài",
  "postUrl": "https://www.instagram.com/p/SHORTCODE/",
  "image": "images/perth-2026-09-24.jpg",
  "like": 10000,
  "comment": 500,
  "share": 200,
  "generators": [
    { "name": "Generator 1", "url": "https://...." },
    { "name": "Generator 2", "url": "https://...." }
  ]
}
  • image: dán URL ảnh hoặc lưu file vào thư mục images/ rồi ghi đường dẫn tương đối.
  • Lấy ảnh: mở bài Ins → click ảnh → Copy image address, hoặc tải về repo.
  • postUrl: link bài (dạng /p/… hoặc /reel/…).
  • id phải khác nhau từng bài. Bài mới để date mới hơn để hiện trên cùng.
